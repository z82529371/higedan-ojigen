# 一般瀏覽模式與開發對齊模式解耦

## 背景與問題
開發與校對時間軸時，需要在畫面上呈現大量的控制介面，包括微調按鈕（`[-5s]` `[-1s]` `[-0.1s]` `[+0.1s]` `[+1s]` `[+5s]`）、鎖定開關、時間標籤 (`12.5s ~ 18.0s, 5.5s`) 以及即時剩餘秒數倒數 (`▶ 已唱 2.3s / 剩 3.2s`)。如果將這些除錯與對齊控制項常駐於畫面上，會使一般的聽歌／應援練唱介面變得過於雜亂，且極易誤觸。

## 決策
引入頂層模式切換控制 `devMode`：
1. **`🎵 一般瀏覽模式`（預設）**：為歌迷提供極致乾淨的閱讀與應援體驗。隱藏所有微調按鈕、鎖定按鈕、區間秒數與倒數計時，僅保留歌詞文字、應援標記與當前行藍色高亮。
2. **`🛠️ 開發對齊模式`**：一鍵開啟打點對齊功能。顯示全套微調按鈕、鎖定開關、即時對齊完成率百分比標籤，以及毫秒級進度與秒數資訊。

## 後果
- **正面**：兼顧了「開發創作者的對齊效率」與「最終使用者的閱讀美觀」，徹底避免非開發情境下的 UI 雜亂與誤觸。
- **負面**：組件需根據 `devMode` 條件式渲染控制列與秒數標籤。
