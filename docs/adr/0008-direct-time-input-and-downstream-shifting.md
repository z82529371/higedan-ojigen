# 間奏開頭秒數直接輸入與後續句子整段平移機制

## 背景與問題
當樂曲出現長時間的無歌詞間奏，或段落開頭的時間軸與音樂節奏存在落差時，僅依靠按鈕以 `±0.1s~±5s` 逐步調整結束時間極為費時。使用者需要能夠在間奏結束開唱的當下，直接精準鍵入目標開頭秒數，並使後續整段歌詞自動同步接續。

## 決策
1. **開頭秒數直接打字框（Direct Start-Time Entry Input Box）**：在開發對齊模式（Dev Mode）下，每句歌詞旁提供專屬的「開頭秒數」數字輸入框（`72px` 粗體高亮）。使用者可以按下 `Enter` 鍵或觸發 `Blur` 焦點離去，直接將該句開唱時間指定為精準小數。
2. **整段長度保留與下游同幅平移（Downstream Equal Offset Shifting）**：當設定第 $i$ 句的開頭時間為 $T_{\text{target}}$ 時，計算時間差 $\Delta = T_{\text{target}} - \text{start}_i$。保持本句及後續所有未鎖定句子的唱秒長度（$\text{end} - \text{start}$）固定，並將 $\Delta$ 同步套用至後續所有未鎖定句子的 `start` 與 `end`。
3. **上一句邊界硬性保護（Previous Line Boundary Clamping）**：輸入的開頭秒數下限受限於上一句的結束時間（$\text{end}_{i-1}$），防止使用者手誤鍵入過小的時間點導致時間軸倒退或與上一句歌詞重疊。
4. **開發模式元件尺寸加大（Dev Mode Control Enlargement）**：微調按鈕與鎖定按鈕統一由原本微小的 `10px` 加大至 `13px`（配合 `6px` 圓角與大點擊邊界），提升行動端與桌面端的操作體驗。

## 後果
- **正面**：間奏對齊效率顯著提升，打字輸入即可瞬間完成整段落對齊；防護機制確保歌詞不會重疊倒退。
- **負面**：需維護額外的直寫 state 邏輯與輸入框焦點綁定機制。
