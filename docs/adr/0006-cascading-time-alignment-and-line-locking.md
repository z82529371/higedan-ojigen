# 連鎖無縫時間對齊、剩餘時間平分與行鎖定機制

## 背景與問題
歌曲歌詞對齊時，若單獨修改某句歌詞的開始或結束時間，極易產生歌詞間的「時間重疊」或「無人唱的空隙（Gap）」。此外，傳統的單向推擠會導致調整某句時，後續已精準對齊好的句子被意外推亂。

## 決策
1. **無縫邊界移動（Seamless Boundary Shifting）**：微調第 $i$ 句時，固定其 `start` 時間，僅調整其 `end` 時間；下一句 $i+1$ 的 `start` 時間自動同步接齊該 `end` 秒數，確保句與句之間 $0$ 空隙。
2. **剩餘時間平分算法（Downstream Even Distribution）**：調整第 $i$ 句 `end` 所釋放或佔用的時間差，不只擠壓下一句，而是自動平均分配（Equally Distribute）給後續所有「未鎖定」的句子，保持時間軸間距均勻。
3. **行鎖定機制與有序序列化（Line Locking & Ordered Serialization）**：每句提供 `lockedLines` 鎖定狀態（並持久化寫入 JSON 檔，序列化時強制按數字由小到大升冪排序以維持資料檔的整潔與版本控制易讀性）。已被鎖定的句子其時間點固定不可變，連鎖推擠與平分算法在遇到鎖定行時自動停止，保障已校對完成的句子不受影響。
4. **硬性上限限制（Audio Duration Clamping）**：所有時間微調與連鎖計算皆受限於音樂實際總長度（`duration`），避免時間點溢出超越樂曲長度。

## 後果
- **正面**：打點過程極度直觀流暢，不再發生時間重疊報錯，對齊完成的段落可完全鎖定保護。
- **負面**：需維護額外的 `lockedLines` 狀態，並需在前端對齊邏輯中處理區域連鎖邊界計算。
