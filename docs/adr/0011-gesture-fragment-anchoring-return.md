# 手勢片段錨定回歸（取代 ADR 0010 決策 2）

## 背景與問題
ADR 0010 決策 2 移除「括號染色與手勢垂直置頂」，主張手勢一律在標記列顯示 emoji。但實作與歌曲資料演進後發現：手勢動作帶有 `text` 且命中歌詞片段時，將 Emoji 錨定於該片段正上方比在行標記列重複顯示更精準、畫面更乾淨，故在程式碼（`lyricColoring.ts` 的 `attachedMarkers` 片段錨定）與 CONTEXT.md 中重新引入片段錨定。

## 決策
1. 手勢動作有 `text` 且命中涵蓋歌詞行時，手勢 Emoji 錨定於該文字片段正上方（片段錨定標記），並從行標記列移除，不重複顯示。
2. 多個手勢標記對到同一片段時，在片段上方依動作順序橫向並排。
3. 合唱動作命中時僅片段染色、不印重複文字標記；未命中或無 `text` 者維持行標記列／獨立標記列。
4. `ADR 0010 決策 2 已過時`：不再以括號格式觸發局部染色，亦不做整行垂直置頂，僅錨定命中片段。

## 後果
- 手勢標記錨定重現，但僅限「有 `text` 且命中」的場合；與 ADR 0010 不同點是不再依賴括號格式、也不做垂直整行置頂，僅錨定命中片段。
